# Rust Backend Service (Zero To Production Style)

This project is a backend service built with Rust as part of my journey toward production-level backend development.

It is inspired by the "Zero To Production in Rust" approach and focuses on building real-world backend systems using modern Rust tooling.

---

## 🚀 Overview

This project implements a simple REST API backend service.

It demonstrates how to:
- Build a production-style backend in Rust
- Structure scalable API services
- Work with async programming
- Integrate a database layer

The goal is to simulate real backend service architecture used in production systems.

---

## 🛠️ Tech Stack

- Rust
- Axum (Web framework)
- Tokio (Async runtime)
- PostgreSQL
- SQLx (Database access layer)
- Docker (for containerization)

---

## 📦 Features

- REST API endpoints
- Async request handling
- Database integration (PostgreSQL)
- Clean project structure (modular architecture)
- Environment-based configuration
